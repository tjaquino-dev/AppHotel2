# 🏨 App Hotel

Aplicativo desenvolvido em .NET MAUI para a disciplina de Desenvolvimento Mobile.

O App Hotel permite simular uma reserva de hospedagem, oferecendo ao usuário uma interface intuitiva para selecionar datas, escolher o tipo de quarto e informar a quantidade de hóspedes.

---

# 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de aplicar conceitos de:

- Desenvolvimento Mobile com .NET MAUI
- Interface gráfica utilizando XAML
- Programação em C#
- Navegação entre telas
- Manipulação de eventos
- Componentes visuais do .NET MAUI
- Validação de elementos da interface

---

# 🚀 Funcionalidades

✅ Seleção de data de Check-in

✅ Seleção de data de Check-out

✅ Escolha do tipo de quarto

✅ Controle da quantidade de hóspedes

✅ Confirmação de reserva

✅ Tela Sobre

✅ Interface personalizada

# 📱 Componentes Utilizados

## Image

Exibe a imagem principal do hotel.

## DatePicker

Permite selecionar as datas de entrada e saída.

## Picker

Permite selecionar o tipo de quarto.

### Opções Disponíveis

- Standard
- Luxo
- Suíte Master

## Stepper

Permite definir o número de hóspedes.

## Label

Utilizado para exibição de informações e títulos.

## Button

Utilizado para executar ações da aplicação.
